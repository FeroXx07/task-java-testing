# task-java-testing

**Descripció**:
- Configurar projectes Java amb Maven o Gradle per a testing.
- Escriure proves unitàries amb JUnit 5.

- Separar lògica de negoci d’entrada/sortida per fer el codi testejable.

- Backend: Java
